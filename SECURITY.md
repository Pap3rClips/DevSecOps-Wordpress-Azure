# Politique de sécurité

Ce dépôt est un projet de démonstration. Si vous identifiez une faiblesse dans la chaîne de déploiement ou dans la configuration, merci de me la signaler **en privé** :

- GitHub : *Security → Report a vulnerability* (signalement privé) ;
- ou par e-mail : hadrienlearn@protonmail.com.

Merci de ne pas ouvrir d'issue publique pour une vulnérabilité. Je m'engage à accuser réception sous 7 jours.

Les décisions de sécurité et les risques acceptés sont documentés dans [docs/adr/](docs/adr/).
